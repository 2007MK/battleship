# ⚓ Odin Battleship

**A classic strategy game built with Vanilla JavaScript, focusing on Test Driven Development (TDD), modular code structure, and complex game logic. Play against computer in this fully interactive browser-based experience.**

### 💡 Project Context

This is a capstone-level project from **The Odin Project's** JavaScript curriculum. The primary focus was on implementing **TDD** using Jest. Every core logic component (Ship, Gameboard, Player) was built by writing tests first, ensuring a robust and bug-free game engine before any UI was developed.

## Features

- **TDD Workflow:** Complete test suites for all game logic using Jest.
- **Game Logic:** Handles ship placement validation, hit/miss tracking, and "sunk" status detection.
- **Modular Architecture:** Separation of concerns between the Game Logic (Pure JS) and the DOM Rendering.

## Tech Stack

- **Language:** Vanilla JavaScript (ES6+)
- **Testing Framework:** Jest
- **Module Bundler:** Webpack
- **Tooling:** Babel, ESLint, Prettier
- **Styling:** CSS3
